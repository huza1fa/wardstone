# Product screenshots

Captured from the running Wardstone console on October 10, 2026. The desktop
viewport was 1280 × 1000 at 2× resolution (2560 × 2000 PNGs); the mobile viewport
was 390 × 844 at 2× resolution (780 × 1688 PNG).

The cases use simulated Jira intake and comment delivery, read-only Google
fixtures, a fictional VPN runbook, live OpenRouter model responses, and configured
public Tailscale documents. They show actual persisted investigations in a
disposable PostgreSQL database. The message-review screenshot shows an edited
draft before submission. No credentials or real requester data are shown.

- `investigations.png`: durable help desk, access, vendor, and systems cases.
- `vendor-review.png`: executive summary, provisional risk, and source provenance.
- `requester-conversation.png`: original question, reviewed wording, delivery,
  and authenticated reply.
- `message-review.png`: original draft and exact operator-edited message.
- `access-policy.png`: group-membership proposal, arguments, citation, and denial.
- `overview.png`: operating mode, metrics, and connector setup/readiness.
- `mobile-overview.png`: responsive console at a phone viewport.

The PNGs are unmodified browser captures and can be used in project documentation
or the project author's personal site. The temporary capture harness, provider
credentials, and database are excluded from Git.
